# envelope: landing page of the "מעטפת חוץ" Google Ads campaign

`envelope.html` is a copy of the home page (`index.html`), generated by `tools/make-envelope.py` and served at
`https://www.supertzel.co.il/envelope` (`vercel.json` has `cleanUrls`, so no rewrite is needed). `index.html` is not modified.
Nothing links to it and it has `<meta name="robots" content="noindex, nofollow">`.

Ad final URL: `https://www.supertzel.co.il/envelope?landing=1`

## What differs from the home page (everything else is the same file)

| Part | Home page | /envelope |
|---|---|---|
| Indexing | indexed | `noindex, nofollow` |
| Tab title | IL Projects \| סופר צל — מעטפת מקצועית לבית ולמרחב החוץ | מעטפת חוץ שלמה לבית \| IL Projects |
| Conversions | counted only with `?landing=1` | the page adds `landing=1` to its address if missing (`history.replaceState`, no reload), so leads, WhatsApp and calls always count; `analytics.js` is unchanged |
| Path on arrival | `?path=` or the last choice in the session, otherwise none | `?path=` if given, otherwise "מעטפת מלאה" (like `/?path=full`) |
| Long form, step 1 options | הצללה, קירוי וחיפויים · הקמת גינה ופיתוח נוף · פתרונות אלומיניום ועץ בהתאמה אישית · בנייה קלה, תוספות חוץ וחדרי שמש | מעטפת חוץ מלאה לבית (preselected) · סגירת זכוכית לפנטהאוז או למרפסת · פרגולת אלומיניום · פרגולת תריס חשמלית · דק, ריצוף וחיפוי · עדיין בודקים אפשרויות |

| WhatsApp and lead text | "היי, הגעתי מהאתר…" | "היי, הגעתי מדף מעטפת החוץ באתר…" |

Header, logo, footer, reviews (customers' own words from Google), floating buttons, lead modal and all scripts are the home page's.
Leads carry `עמוד: /envelope` and the UTM/gclid (added by `lead.js`), so they can be told apart from home page leads.

## Rebuilding

After a change to `index.html`: `python3 tools/make-envelope.py`. Every replacement must match exactly once; otherwise the script names
the one that no longer matches and writes nothing.

## To stop

Point the ads back to `/?path=full&landing=1` and delete `envelope.html`.
